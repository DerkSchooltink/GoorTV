# GoorTV

Open-source M3U / Xtream-compatible media player for Android TV and Android phones.

- **Source code:** [github.com/DerkSchooltink/GoorTV](https://github.com/DerkSchooltink/GoorTV)
- **Releases:** [github.com/DerkSchooltink/GoorTV/releases](https://github.com/DerkSchooltink/GoorTV/releases)
- **Privacy policy:** [/privacy/](privacy.md)

## Install outside Google Play

Use [Obtainium](https://github.com/ImranR98/Obtainium): add the source
`https://github.com/DerkSchooltink/GoorTV` and it auto-updates from each release.
Or download the latest `app-release.apk` from
[Releases](https://github.com/DerkSchooltink/GoorTV/releases) and sideload it.
